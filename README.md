# Luffy Desktop

My Straw Hat themed Windows desktop, built entirely in code:

* **Taskbar Glass**: a Mac-style taskbar with icons only, instant auto-hide, and icons that pop in when it appears.
* **Desk Widgets**: macOS-style widgets (folders, to-do, calendar, music, photos, weather, clock, system)
  and a gently animated sunset scene: a drifting straw hat, a sailing ship, seagulls and glittering water.
* **Art scripts**: the wallpaper, folder icons and photos are generated with Python.

Build and restart everything:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```
